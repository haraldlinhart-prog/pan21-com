8. Visitor counting with PAN21counter

We count page views with our own visitor counter PAN21counter (pan21counter.de). It does not set cookies and does not create user profiles. When a page is requested, a truncated hash value that changes daily is derived from the IP address to avoid counting the same visitor more than once per day; the IP address itself is not stored. Individual page views are deleted after three days; after that, only aggregated daily totals remain. The legal basis is Art. 6(1)(f) GDPR (legitimate interest in simple reach measurement).
